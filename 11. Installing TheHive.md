Go to your windows VM. Click on the start menu, search for powershell and right click on it to open as administrator.

If you already have powershell open from the last phase, make sure you're not already in a ssh session with the Wazuh cloud instance. if so type:
```
exit
```
You will be returned to your powershell prompt.

At this point we will ssh into TheHive cloud instance.
```
ssh root@45.76.8.244
```
Be sure to replace the IP address in the command above with your instance's IP address.

When prompted type `yes` and hit enter.

now copy and paste the password from the same place we found out cloud instances IP address. <br>
when you paste all you need to do is **right click** you won't see anything happen but it should be there. hit enter and it should log you in. <br>
If it doesn't you will have to type the password in manually. <br>
Note: you will not see the password appear weather you paste it with a right click or type it manually.

### Download THeHive

Return to your host computer and go to <a href="https://docs.strangebee.com/thehive/installation/installation-guide-linux-standalone-server/">this link</a> to download the hive. <br>
<a href="https://docs.strangebee.com/thehive/installation/installation-guide-linux-standalone-server/"><img src="https://img.shields.io/badge/-The_Hive-0072b1?&style=for-the-badge&logoColor=white" /></a>

scroll down and copy the code under "Step 1: Install required dependencies". I have also provided the code below.
```
sudo apt update
sudo apt install wget curl gnupg coreutils apt-transport-https git ca-certificates ca-certificates-java software-properties-common python3-pip lsb-release unzip
```

Paste this code into our ssh session.

Now return to the web browser, scroll down further and you will see "Step 2: Set up the Java virtual machine (JVM)". copy the code from that section and paste it into your ssh session.
```
wget -qO- https://apt.corretto.aws/corretto.key | sudo gpg --dearmor -o /usr/share/keyrings/corretto.gpg
echo "deb [signed-by=/usr/share/keyrings/corretto.gpg] https://apt.corretto.aws stable main" | sudo tee -a /etc/apt/sources.list.d/corretto.sources.list
sudo apt update
sudo apt install java-common java-11-amazon-corretto-jdk
echo JAVA_HOME="/usr/lib/jvm/java-11-amazon-corretto" | sudo tee -a /etc/environment
export JAVA_HOME="/usr/lib/jvm/java-11-amazon-corretto"
```


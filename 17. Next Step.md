# combine all tools create working automation

Head over to <a href="https://shuffler.io/">Shuffler.io</a> and create an account. After you create an account, select workflows over to the left.

You can zoom in by scrolling and pan by clicking and dragging.

Click on the Webhook and copy the URI. We'll need to update our Wazuh manager's ossec.conf file and point it towards this URI.

<br>

<img width="626" height="178" alt="image" src="https://github.com/user-attachments/assets/172beef3-1472-4f5b-97c0-efeed8ccf9e2" />

<br>
<br>
<br>
<br>

head over to a PowerShell window and if you haven't already ssh into your Wazuh cloud instance. Once you have open the `ossec.conf` file.

```bash
nano /var/ossec/etc/ossec.conf
```

<br>

<img width="2466" height="1242" alt="image" src="https://github.com/user-attachments/assets/88bdfab8-50a2-4c9a-be7c-68d00e16271b" />

<br>
<br>
<br>
<br>

Scroll down and hit enter in between `global` and `alerts` to create some space. Now copy and paste the following code in that space.
```xml
  <integration>
    <name>shuffle</name>
    <hook_url>YOU_WEBHOOK_URI_HERE</hook_url>
    <rule_id>100002</rule_id>
    <alert_format>json</alert_format>
  </integration>
```

**REPLACE** `YOU_WEBHOOK_URI_HERE` with the URI you copied earlier. Then hit `ctrl` + `x`, then `y` and `enter` to save.

```bash
systemctl restart wazuh-manager.service
```

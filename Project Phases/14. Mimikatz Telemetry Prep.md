### Modify ossec.conf On Wazuh Cloud Instance

If your not already connected, connect to your Wazuh cloud instance via ssh.
```powershell
ssh root@WAZUH_SERVER_IP
```
replace `WAZUH_SERVER_IP` with your IP address.

Copy the ossec.conf file to your home folder.
```bash
cp /var/ossec/etc/ossec.conf ~/ossec_backup.conf
```
You can then use `ls ~/` to make sure the copy has been created.

### Precautionary Steps

Before proceeding, let's take some precautionary steps. We will be downloading Mimikatz. Because it is flagged as a malicious software by many browsers, we may encounter some alarming warning messages. These steps will be to ensure us that even if something truly malicious does infect our VM we have a safe secure backup and our host computer will remain uncompromised.

That said the source from where we will download MimiKatz is trusted. We have nothing to be concerned about. However, percussion is always advised and that is why we will take these steps.

1. Take a snapshot of your VM by going to `vm` > `Settings` > `Take Snapshot...`. Name it "Pre-Mimikatz"

<img width="2876" height="1656" alt="Screenshot 2026-08-07 172513" src="https://github.com/user-attachments/assets/0399fd51-5b5c-423f-8a10-e347fbaf639f" />

<br>
<br>
<br>
<br>

2. Turn off copy and paste. First, open Notepad, then copy and paste the link below into it. We will use this later when downloading Mimikatz.
```URL
https://github.com/gentilkiwi/mimikatz
```
Save the file to your desktop.

<br>

<img width="1828" height="992" alt="image" src="https://github.com/user-attachments/assets/040ee0c1-15c5-4466-b1a9-2657ff1f2346" />

<br><br>

<img width="1472" height="906" alt="image" src="https://github.com/user-attachments/assets/13c1846c-fadd-4e70-ab24-a9c2f0f25fc9" />

<br>
<br>
<br>
<br>

Shut down the VM by clicking the orange pause sign in the upper left.

<br>

<img width="1356" height="582" alt="image" src="https://github.com/user-attachments/assets/dd04cbf5-a125-48ac-b865-4ead1d669450" />

<br>

Go to `VM` > `Settings` > `Options` > `Guest Isolation`. Turn off "Enable drag and drop" and "Enable copy and paste". Then start the VM.

<img width="2876" height="1658" alt="Screenshot 2026-08-07 174517" src="https://github.com/user-attachments/assets/989d2c7a-6ce5-449b-b15c-d0f941a4d0fc" />

3. Make sure your VM is on NAT mode and not Bridged by going to `VM` > `Settings` > `Network Adapter`.

<br>

<img width="1494" height="1428" alt="image" src="https://github.com/user-attachments/assets/a47ffd17-70f8-4d45-b84b-373ea68309ac" />

4. Make sure virus protection is on for your host computer by going to the start menu, searching for "Windows Security", and opening it. You should see green checks across the board.

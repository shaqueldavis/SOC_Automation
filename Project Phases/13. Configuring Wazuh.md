# Configuring Wazuh

Open a web browser on your Windows 11 VM, not your host computer.

Visit your Wazuh dashboard. **REPLACE** the IP address with the IP address of your Wazuh cloud instance.
```
https://45.77.110.252
```

Scroll down and hover over the code under "Run the following commands to download and install the agent:" and click to copy the code. I have included the code here as well.
```powershell
Invoke-WebRequest -Uri https://packages.wazuh.com/4.x/windows/wazuh-agent-4.14.7-1.msi -OutFile $env:tmp\wazuh-agent; msiexec.exe /i $env:tmp\wazuh-agent /q WAZUH_MANAGER='45.77.110.252' WAZUH_AGENT_NAME='Windows-11_SOC-Lab' 
```

Now go back over to your Wazuh manager dashboard by clicking on the 3 lines in the upper left. Go to home > overview. You may need to reenter your password.

If you don't see any agents, like me, we need to enable a couple of rules within Ufw to allow our agent to communicate with our Wazah manager.

connect to you Wazuh cloud instance via ssh using a PowerShell window.
```powershell
ssh root@xxx.xxx.xxx.xxx
```
Replace "xxx.xxx.xxx.xxx" with your Wazuh cloud instances IP address.

Allow port 1515 and 1514.
```bash
ufw allow 1515
```
```bash
ufw allow 1514
```

#### Side Note

If you're like me, you too make mistakes. That said, I realized I named my Instance "SOC-Lab" instead of "SOC-Lab Wazuh". The "Wazuh" portion of the name is important because we will be creating two instances and this particular instance will be used for Wazuh.

To update the name click on the three dots on the right of the instance and chose "Server Details".

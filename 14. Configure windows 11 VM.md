Go to Program Files (x86) > ossec-agent. In this folder locate the "ossec.conf" file.

<br>

<img width="1898" height="1152" alt="image" src="https://github.com/user-attachments/assets/2c14769a-f8ae-4244-8daf-764cc06bd63e" />

Copy the "ossec.conf" file and paste it in the same folder. You will get a warning that "You'll need to provide administrator permission to copy this file". Click continue.

<br>

<img width="1086" height="428" alt="image" src="https://github.com/user-attachments/assets/44668b01-f7c4-4202-9e6e-429457602f8b" />


<br>
<br>
<br>
<br>

You will now have a "ossec - Copy.conf" file. Rename it "backup_ossec.conf". Again, hit continue when prompted.

Now to configure the file, open up Notepad as an administrator by launching the start menu, searching for note pad, right clicking, and choosing "run as administrator". Choose "yes" when prompted by UAC.

<br>

<img width="1878" height="1388" alt="image" src="https://github.com/user-attachments/assets/f14547d5-5c10-429c-96e0-ef0b43419a90" />

<br>
<br>
<br>
<br>

Go to File > open, in the top left corner of Notepad. Navigate to the folder where our "ossec.conf" file is located: <br>
This PC > Local Disk (C:) > Program Files (x86) > ossec-agent

You will not see the file until you change the filter in the bottom right corner from "Text documents (*.txt)" to "All files" <br>
Once you have done so click on the "ossec.conf" file and hit open.

# Configuring TheHive.md

### Configuring Cassandra

If you have not already, open PowerShell by going to the start menu searching for PowerShell, right clicking on it, and selecting run as administrator. 

ssh into your cloud instance for TheHive. Remember your IP address for this cloud instance can be find by logging into your Vultr account going to compute > instances.

connect with ssh to the instance.
```
ssh root@xxx.xxx.xxx.xxx
```
**Remember to replace the "xxx.xxx.xxx.xxx" portion with your IP address

Once your in, Open the file:
```
nano /etc/cassandra/cassandra.yaml
```

Once it is open change the "cluster_name" to your name of choice. It will likely say "Test Cluster" initially.

### Configure TheHive

Before proceeding we need to change permissions for a particular directory. That directory is "/opt/thp". <br>
If we change into the directory with `cd /opt/thp` and list its content with `ll` then we see that "the hive" is owned by the root user and root group.

<br>

<img width="1234" height="220" alt="image" src="https://github.com/user-attachments/assets/6a4deb77-6d1f-40d1-87ab-10b0540881ee" />


<br>
<br>
<br>
<br>

Change the permissions with:
```
chown -R thehive:thehive /opt/thp
```

<br>

<img width="1356" height="230" alt="image" src="https://github.com/user-attachments/assets/33619fe6-bb98-4cb0-b52b-d54320d32549" />

Start configuring the file.
```
nano /etc/thehive/application.conf
```

Scroll down to "hostname" and change the IP address from "127.0.0.1", which is the local host address, to you cloud instances IP address.

<br>

<img width="2328" height="982" alt="image" src="https://github.com/user-attachments/assets/1bd28aae-d53e-4d6c-b85b-e9556c48b774" />

<br>

Change the cluster name from "thp" to you name of choice.

<br>

<img width="2322" height="980" alt="image" src="https://github.com/user-attachments/assets/007738ec-2235-42f0-8cfc-f661f7864f43" />

<br>
<br>
<br>
<br>

Hit `ctrl` + `w` and search for "index.search". Replace the current block:
```
index.search {
  backend = elasticsearch
  hostname = ["127.0.0.1"]
  index-name = thehive
}
```
With this:
```
  index.search {
    backend = elasticsearch
    hostname = ["127.0.0.1"]
    index-name = thehive

    elasticsearch {
      ssl {
        enabled = true

        truststore {
          location = "/etc/thehive/elasticsearch-truststore.p12"
          password = "YOUR_PASSWORD_HERE"
        }
      }

      http {
        auth {
          type = basic

          basic {
            username = "thehive"
            password = "YOUR_PASSWORD_HERE"
          }
        }
      }
    }
  }
}
```
**REPLACE `YOUR_PASSWORD_HERE` with a password of your choosing. Make sure to write this password down for future reference.

Scroll down to "application.baseUrl" and change the IP address from "localhost" to your IP address.

<br>

<img width="2326" height="978" alt="image" src="https://github.com/user-attachments/assets/393f7099-6205-4213-b277-943e1b1c68ff" />

<br>
<br>
<br>
<br>

Now save the file by hitting `ctrl` + `x`. Type `y` for yes to confirm and hit enter. Then hit enter again to save it under the same name.

Create a thehive user.
```bash
sudo /usr/share/elasticsearch/bin/elasticsearch-users useradd thehive -p <thehive_user_password> -r superuser
```
**REPLACE <thehive_user_password> with a password of your choosing**

Confirm that the account exists:
```bash
/usr/share/elasticsearch/bin/elasticsearch-users list

```
In the output you should see `thehive        : superuser`.

Test the new account securely.
```bash
curl --cacert /etc/elasticsearch/certs/http_ca.crt \
  -u thehive \
  https://127.0.0.1:9200
```
Type in the password you just created.

A successful response should contain information such as:
```json
{
  "name": "vultr",
  "cluster_name": "...",
  "version": {
    "number": "..."
  }
}
```

Create a Java truststore for TheHive.
```bash
keytool -importcert \
  -alias elasticsearch-http-ca \
  -file /etc/elasticsearch/certs/http_ca.crt \
  -keystore /etc/thehive/elasticsearch-truststore.p12 \
  -storetype PKCS12
```

Verify it.
```bash
sudo -u thehive test -r /etc/thehive/elasticsearch-truststore.p12 && echo "TheHive can read the truststore"
```

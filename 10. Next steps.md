To access our Wazuh cloud instance, we have 2 options.

Option 1. Use Vultr's built in console by clicking the monitor icon towards the top of the window. Click it and it will drop you into a shell.

Option 2. SSH in from your host computer or the Windows 11 VM we created earlier. I personally will choose to SSH in through the Windows 11 VM. SSH from you host is the cleanest option but SSH through from the VM avoids executing any accidental commands on your host computer. 

That said, lets open up our Windows VM. from the start menu search for "powershell", right click it when it pops up, and chose "Run as administrator"

Type in the command:
```
ssh root @xxx.xxx.xxx.xxx
```

**make sure to REPLACE `xxx.xxx.xxx.xxx` with your IP address. In my case the command looks like `ssh root @45.77.110.252`.

Hit enter.

Type "yes" and hit enter again.

Copy your password from your Wazuh instance and paste it in. You won't see it pop up but hit enter and it should go through. If it doesn't there is an eyeball icon beside the password. click on that and it will reveal the full password. You can then type it in manually.

Once you're connect, you will see your prompt change.

Now type in 
```
 cloud-init status`
```

You should receive the status `done`. <br> 
If you receive the status `running`, wait a few minutes and check again.

Before we attach anything, we want to head over to the hive and create an account for this automation.

Navigate to your hive dashboard from a web browser on your host.
```URL
http://45.76.8.244:9000
```
**REPLACE** `45.76.8.244` with your IP address.

Login using the default credentials. <br>
Username:
```
admin@thehive.local
```
Password:
```
secret
```
